# ⚡ Text-to-Circuit AI Assistant

An AI-powered Streamlit application that understands natural-language electronics requests and generates circuit information, component lists, explanations, calculations and educational circuit diagrams.

## Features

- Natural-language circuit input
- Gemini AI integration
- Circuit/device detection
- Component identification
- Circuit diagrams
- Engineering calculations
- Working-principle explanations
- Safety information
- PNG circuit download
- Professional Streamlit dashboard

## Supported Examples

- LED circuit
- Voltage divider
- RC filter
- RL circuit
- RLC circuit
- Common emitter amplifier
- Inverting op-amp
- Bridge rectifier
- Zener regulator
- Transistor switch
- 555 timer
- Fire detection system
- Security alarm
- Automatic street light
- Temperature controlled fan
- Battery charger
- Walkie-talkie
